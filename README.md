# 🎮 GetRekt

Game recorder for Windows with instant **Reclips**: press a key and the last 30 seconds are saved. Built in Rust, light on your PC.

## ⬇️ Download

**[Get the latest version here](https://github.com/heyjeay/getrekt_public/releases/latest)**: under **Assets**, click `GetRekt_x.x.x_x64-setup.exe`.

## 📦 Install guide

**1. If your browser complains about the download:**
- **Chrome:** click the download arrow → **Keep**
- **Edge:** `⋯` menu on the download → **Keep** → **Show more** → **Keep anyway**

**2. Run the setup.** If Windows shows the blue **"Windows protected your PC"** screen:
- Click **More info**
- Click **Run anyway**

> This shows up because GetRekt is an indie tester build, not from a big-name publisher. It only asks the first time.

**3. Follow the installer.** No admin rights needed; it adds GetRekt to your Start menu and desktop.

**4. Open GetRekt and play.** It finds your game on its own.

## 🎬 Controls

| Key | What it does |
| --- | --- |
| **F4** | **Reclip**: save the last 30 seconds (change the length in Settings) |
| **F5** | Start / stop recording |
| **Shift + F5** | Pause / resume |

Hotkeys work in fullscreen games and can be changed in **Settings**. Clips are saved to `Videos\GetRekt`.

## 🔄 Updates

GetRekt **updates itself**. When a new version is out, a blue **Update** pill appears in the header: one click installs it and reopens the app. You never need to come back to this page.

## 🐛 Found a bug?

Tell us what you were recording and what happened. In any clip, the **Advanced** button shows the video quality and smoothness numbers, and a screenshot of it helps a lot.
